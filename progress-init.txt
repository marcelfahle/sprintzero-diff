## Feature 1.6 - API Routes: Raw Content and Cache Refresh [COMPLETE] - 2026-03-11

Implemented:
- Created src/app/api/raw/[gistId]/route.ts — GET handler that fetches a gist and returns raw file content
  - Accepts ?file= query param to select a specific file, defaults to first file
  - Returns correct Content-Type based on file extension via getMimeType()
  - Sets Content-Disposition inline header and Cache-Control (86400s)
  - Returns 404 if gist not found or has no files
- Created src/app/api/refresh/[gistId]/route.ts — POST handler for on-demand cache busting
  - Validates gist ID format (hex 20-32 chars) before processing
  - In-memory rate limiting: rejects 429 if same gist refreshed within 60 seconds
  - Calls revalidateTag(`gist-${gistId}`, { expire: 0 }) to bust Next.js fetch cache

Verified:
- `bun run build` succeeds with zero errors — both routes listed as dynamic (ƒ)
- `bun run lint` (oxlint) passes with 0 warnings/errors on 16 files
