## Feature 1.6 - API Routes: Raw Content and Cache Refresh [COMPLETE] - 2026-03-11

Implemented:
- Created src/app/api/raw/[gistId]/route.ts — GET handler that fetches a gist and returns raw file content
  - Accepts ?file= query param to select a specific file, defaults to first file
  - Returns correct Content-Type based on file extension via getMimeType()
  - Sets Content-Disposition inline header and Cache-Control (86400s)
  - Returns 404 if gist not found or has no files
- Created src/app/api/refresh/[gistId]/route.ts — POST handler for on-demand cache busting
  - Validates gist ID format (hex 20-32 chars) before processing
  - In-memory rate limiting: rejects 429 if same gist refreshed within 60 seconds
  - Calls revalidateTag(`gist-${gistId}`, { expire: 0 }) to bust Next.js fetch cache

## Feature 2.2 - Shiki Code Renderer with Per-Block Copy Buttons [COMPLETE] - 2026-03-11

Implemented:
- Created src/lib/shiki.ts — Shiki code highlighting utilities
  - getShikiLang(filename, language) maps file extensions and GitHub language strings to Shiki language identifiers
  - Covers 40+ language mappings (ts, tsx, py, rb, rs, go, sh, etc.) with special filename handling (Dockerfile, Makefile)
  - highlightCode(code, lang) renders code to HTML using Shiki's codeToHtml with github-dark-default theme
  - Falls back to plain "text" if language isn't supported by Shiki
- Created src/components/code-renderer.tsx — async server component
  - Takes code, filename, and language props; calls getShikiLang then highlightCode
  - Uses dangerouslySetInnerHTML to render Shiki's highlighted HTML output
  - Styled: rounded-lg, border neutral-800, bg neutral-900, font-mono text-sm, overflow-x-auto
  - Overrides Shiki's default pre/code backgrounds to transparent so container styles apply
- Created src/components/copy-button.tsx — reusable client component
  - Takes getText callback (lazy evaluation — doesn't capture text at render time)
  - Clipboard icon → checkmark with 2s reset using lucide-react Copy/Check icons
  - Styled to match neutral dark theme with hover state
- Created src/components/code-block-enhancer.tsx — client wrapper that injects copy buttons onto <pre> elements
  - Uses useEffect to scan for <pre> elements inside the wrapper on mount
  - Creates portal mount points positioned absolute top-right on each pre block
  - Uses React createPortal to render CopyButton into each mount point
  - Extracts text content from <code> or <pre> for clipboard
  - Marks enhanced blocks with data-enhanced to avoid duplicates
  - Cleans up on unmount
